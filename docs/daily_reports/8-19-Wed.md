### What I Learned

    Task 17. 
          Release/Tag, Raw Commit SHA makes documentation reproducible:
                             someone re-cloning main next month may see different code.

        '''
           # Clone at a specific tag directly (also grab submodules, since this repo has one)
           git clone --branch v1.1.0 --recurse-submodules https://github.com/HybridRobotics/Berkeley-Humanoid-Lite.git

           # Or if you already cloned main:
           git checkout v1.1.0
           git submodule update --init --recursive
        '''

        '''
           # Either way, get the exact commit SHA you're sitting on:
           git rev-parse HEAD
        '''
        That last command's output is the string you paste into your asset map — e.g. "cloned v1.1.0, commit <SHA>, inspected 2026-08-19." That sentence is what makes Task 17 and the "another engineer can reproduce this" acceptance criterion actually true.
